# AyayaJpType

日语盲打闯关：题目只给中文，凭记忆打出 N5 / N4 / N3 单词或例句的罗马音。

线上：https://ayaya114514.github.io/AyayaJpType/

- 单词来自 [AyayaJp](https://github.com/ayaya114514/AyayaJp) 的规范词表（`〜円`、`お〜` 这类词缀除外），每个级别按固定顺序打乱后每关约 20 词。
- 句子来自 AyayaJp 的单词例句和语法例句（去重后归到首次出现的级别），读音和罗马音取 AyayaJp 页面上实际显示的那份（审核过的注音和分词），每关 10 句；标点不用打。含 CD、ATM 这类拉丁字母的 2 句不收。单词和句子的进度、错题集分开。
- 不显示词形、假名和罗马音，打对的部分才显示出来；卡住按 `Tab`（手机点「不会」）看答案再照打。
- 打出来就算对，中途打错的键只影响准确率；按 `Tab` 看过答案的才算错。每关记错得最少的那次，**对 5 个及以上**就解锁下一关。进度存在浏览器 `localStorage`（旧的星级存档自动换算）。
- 界面是一条夜里的电车线：N5 / N4 / N3 是三条线，每关是一站，过了的站盖一个写着错几个的纪念章（全对是「満点」）；打字卡片是站名牌，结算是一张车票；单词是「各停」，句子是「特急」。
- 错题集（忘れ物センター）：看过答案的词自动收进来（按 N5 / N4 / N3 筛选），每次练最近错的 20 个；闯关或练习里连续 2 次不看答案打出来才移出。错题练习不记成绩、不影响解锁。
- 多读音的词任一读法都算对（日本 にほん / にっぽん、梅雨 つゆ / ばいう）；中文释义完全相同的词互相算对（幸福：幸福 / 幸せ）。
- 按假名逐个判定，Hepburn / 訓令式（shi/si、tsu/tu、chi/ti、fu/hu、ji/zi）、`nn` / `n'`、促音双写或 `xtu`、长音 `-` 都可以；助词 は / へ / を 按词表 romaji 接受 wa / e / o。

## 开发

```sh
source ~/.nvm/nvm.sh && nvm use
npm install
npm run dev
npm test          # 判定器单测 + 全词表逐词回放
npm run build
```

AyayaJp 词表或例句更新后：`npm run sync:words` / `npm run sync:sentences`（默认读 `../AyayaJp`），会校验每个词、每句的 romaji 都能按读音打出来，再生成 `src/words.json` / `src/sentences.json`。句子数据单独打包，切到句子模式才加载。
